## LinkedIn project description
Built GeoPredict AI, a regional mineral-prospectivity ML project for Western Australia's Eastern Goldfields. The workflow integrates multi-element geochemistry, mapped structures, magnetic texture and Bouguer gravity under geographic cross-validation. A key part of the project was diagnosing historical exploration bias: drill-density features improved raw performance but largely encoded where previous exploration had occurred, so they were excluded from the final scientific model. The final workflow reduced 206 predictors to 39 stable features and achieved ~0.96 spatial-CV ROC-AUC. Grid 33 emerged as the strongest integrated screening target, while Grid 149 was the strongest high-novelty geophysics-led candidate.
